# bin-pwned

**Desciption:**  
A CLI tool that scans your system binaries for known CVEs, showing which programs are safe ✅ or vulnerable ❌ with short CVE summaries.  

**Installation:**  
```
git clone https://github.com/jaduplansti/bin-pwned
cd bin-pwned
pip install -r requirements.txt
python bin_pwned.py
```
